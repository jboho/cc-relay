# cc-relay

Cross-machine, cross-account messaging between interactive Claude Code sessions: a Channels MCP server on each machine and a small end-to-end-encrypted hub on one Mac, reachable over Tailscale or the local network.

Status: planned, not built. Design: [.ai/docs/plans/2026-09-23-cc-relay-design.md](.ai/docs/plans/2026-09-23-cc-relay-design.md). Build plan (M0–M2): [.ai/docs/plans/2026-09-23-cc-relay-m0-m2.md](.ai/docs/plans/2026-09-23-cc-relay-m0-m2.md).
